# GR | Direct Notes

Chrome MV3 sidePanel-виджет для локальных заметок к кампаниям, группам объявлений и объявлениям в Яндекс.Директе.

## MVP

- работает только на `direct.yandex.ru`;
- хранит данные в `chrome.storage.local`;
- добавляет кнопки `З` в таблицах Директа рядом с колонками кампании, группы и объявления;
- по клику на `З` открывает поле комментария прямо на странице;
- если заметка уже есть, поле открывается с ее текстом и датой последнего редактирования;
- добавляет, обновляет, копирует и удаляет заметки;
- показывает список заметок по типу: кампании, группы или объявления;
- не меняет значения `input`, `textarea` и `contenteditable` на страницах Директа.

## Установка

1. Открыть `chrome://extensions/`.
2. Включить "Режим разработчика".
3. Нажать "Загрузить распакованное расширение".
4. Выбрать папку `N:\Python\Python Pro\chrome_direct_notes`.
5. Закрепить расширение в Chrome.
6. Открыть страницу Яндекс.Директа и sidePanel расширения.
