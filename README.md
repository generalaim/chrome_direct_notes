# GR | Direct Notes

Chrome MV3 sidePanel-виджет для локальных заметок к кампаниям и группам объявлений в Яндекс.Директе.

## MVP

- работает только на `direct.yandex.ru`;
- хранит данные в `chrome.storage.local`;
- определяет текущую кампанию и, если возможно, группу объявлений по URL и заголовкам страницы;
- добавляет, обновляет, редактирует, копирует и удаляет заметки;
- показывает список заметок по типу: кампании или группы;
- ставит компактный зеленый маркер на странице, если для текущей сущности есть заметка;
- не меняет значения `input`, `textarea` и `contenteditable` на страницах Директа.

## Установка

1. Открыть `chrome://extensions/`.
2. Включить "Режим разработчика".
3. Нажать "Загрузить распакованное расширение".
4. Выбрать папку `N:\Python\Python Pro\chrome_direct_notes`.
5. Закрепить расширение в Chrome.
6. Открыть страницу Яндекс.Директа и sidePanel расширения.
